# openhouse-maps

Weekly open-house reference maps, generated by the house-lab openhouse scanner
(`house-lab/tools/openhouse_scan`) and pushed from the Mac Mini digest job.
Each page is a self-contained Leaflet/folium map of that week's digest listings.

- `YYYY-MM-DD.html` — the map for that week's digest
- `index.html` — always the latest week
